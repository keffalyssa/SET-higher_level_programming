# 0x12-javascript-warm_up

JavaScript warm-up exercises to learn the basics of JavaScript programming.

## Learning Objectives

- Understand how to run JavaScript files
- Learn to work with variables (const, let)
- Use console.log() for output
- Follow JavaScript best practices and linting standards

## Requirements

- Node.js installed
- `semistandard` for code linting

## How to Run

```bash
./0-javascript_is_amazing.js
```

Or with Node directly:

```bash
node 0-javascript_is_amazing.js
```

## Files

### 0-javascript_is_amazing.js
- Prints "JavaScript is amazing" to the console
- Uses a const variable to store the string
- Uses console.log() for output
- Does not use var keyword
